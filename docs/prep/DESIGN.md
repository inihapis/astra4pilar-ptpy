# DESIGN GUIDELINE — Astra Impact Awards Prototype (Revised)

## Design Direction

Visual platform mengikuti nuansa:

* Astra
* SATU Indonesia Awards
* Corporate social impact platform

Target visual:

* profesional
* modern
* bersih
* human-centered
* mudah dipahami

---

# UX Goals

## Public User

* Tidak intimidating
* Tidak terasa seperti form administratif
* Flow terasa ringan
* Step-by-step jelas

## Admin

* Cepat scanning data
* Cepat filtering
* Mudah shortlist

## Judge

* Fokus membaca submission
* Fokus penilaian
* Minimal distraction

---

# Landing Page Direction

## Layout

Landing menggunakan:

* hero section
* 4 pillar cards
* CTA utama
* smooth transition ke form

---

## Hero Section

Menampilkan:

* Judul program
* Deskripsi singkat
* CTA “Daftar Sekarang”

---

# Placeholder Branding

Karena masih prototype:

* logo Astra menggunakan placeholder text
* logo Desa Sejahtera Astra menggunakan placeholder text

Contoh:

* [ASTRA LOGO]
* [DESA SEJAHTERA ASTRA]

---

# 4 Pillar Layout

Pilar ditampilkan sebagai:

* grid 2x2
* interactive cards

Pilar:

* Kesehatan
* Pendidikan
* Lingkungan
* Kewirausahaan

---

# Visual Style

## Tone

* Clean
* Corporate
* Social impact
* Minimal modern

---

## Color Direction

Menggunakan nuansa:

* Biru Astra
* Putih
* Light gray
* Accent soft blue

Hindari:

* warna terlalu neon
* gradient berlebihan
* visual gaming-style

---

# Typography

## Style

* Modern sans-serif
* Bersih
* Mudah dibaca

---

## Hierarchy

Gunakan hierarchy jelas:

* Heading besar
* Subheading ringan
* Body text nyaman dibaca

---

# Form Experience

## Multi-step Form

Form menggunakan:

* progress indicator
* step transition
* autosave feedback

---

## Form UX Principles

* 1 fokus utama per step
* Hindari terlalu banyak field dalam 1 layar
* Gunakan textarea luas untuk narasi

---

# Wilayah Selector

## Nested Region Selector

Wilayah menggunakan:

* dropdown bertingkat

Flow:

* Provinsi
  → Kabupaten/Kota
  → Kecamatan
  → Desa

---

## Desa Example Hint

Field desa menampilkan:

```txt
Desa Sukamaju - Kecamatan Cisarua - Kabupaten Bandung Barat
```

Sebagai:

* placeholder
* helper text

---

# Dropdown Interaction

## Grup Astra

Menggunakan:

* searchable dropdown
* creatable option

User dapat:

* memilih opsi tersedia
* mengetik opsi baru

---

# Dashboard Direction

## Admin Dashboard

Fokus:

* data overview
* filtering
* status management

Gunakan:

* table sederhana
* sticky filter section
* status badge

---

## Judge Dashboard

Fokus:

* membaca submission
* scoring cepat

Gunakan:

* split layout
* submission content + scoring sidebar

---

# Interaction Style

## Animation

Gunakan:

* subtle transition
* smooth hover
* soft fade

Hindari:

* animation berlebihan
* motion terlalu agresif

---

# Responsive Behavior

## Mobile

Public form harus:

* mobile friendly
* nyaman digunakan di layar kecil

---

## Desktop

Dashboard admin/juri:

* desktop-first
* table optimized

---

# Overall Experience

Platform harus terasa seperti:

* sistem kurasi program sosial,
  bukan:
* form lomba sekolah
